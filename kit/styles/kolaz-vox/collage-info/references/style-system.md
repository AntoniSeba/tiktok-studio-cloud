# 风格系统 · 半调纸拼贴 · 信息版

所有类和变量都在 `assets/collage.css` 里现成可用，先引它再谈别的。这份文档解释每个部件为什么长这样，避免改样式时破坏家族感。

## 视觉 DNA（继承 gbro-collage-ip）

拼贴 IP 动画的六要素，信息版全部保留，只是把"角色+机器"换成"卡纸+信息"：

1. **平涂纸场**：一个纯色底 + 纸纤维 + 印刷网点 + 极轻暗角。`.fiber`（feTurbulence，multiply .30）+ `.grain`（4px 网点，.10）+ `.vig`。这三层永远压在最上、不参与动画。渐变背景会立刻脱离纸质感，禁止。
2. **卡纸剪片**：`.cut` = 卡纸色 + 2px 暖奶油 keyline（`#FCF8ED`，模拟刀口高光）+ 统一纸影。层级用卡纸色分：主卡 `#F6F1E4` / 次级 `.dk #EAE1CC` / 点色卡 `.acc`。±0.3–1.6° 手摆微旋是必须的——正得笔直就成了 PPT。
3. **单一点色**：一帧只有一个 accent（body class 决定），面积 <10%。另放一个 `.blob` 出画大圆做色彩重心（半径过大、被画框裁掉一部分才对，完整的圆会变成装饰）。
4. **半调照片**：`.shot` = 灰度 + 4px 网点 multiply。真实截图进来也要过这层处理（`img.shot-img` 自带 grayscale+contrast filter），保持印刷品质感。
5. **撕边地层**：底部字幕安全区用 `.torn-11/22/33` 三条不同随机种子的撕边纸层（呼应拼贴条的纸片地基）。规则锯齿看起来像机器切的，必须用预生成的不规则 polygon。
6. **统一纸影**：全画面只有一种影子方向和柔度（`--shadow` / `--shadow-sm`），影子跟着剪片动。

## 布局硬规则

- 画布 1080×1920；**信息只能落在 y ≤ 1280**，底部 640px 是字幕安全区，只放纸场延续与撕边地层，连低对比的说明文字都不放。
- 每帧 3–6 个大组，留白宁多勿少。挤了就删信息，不缩字号。
- 全帧只允许**一处**点色批注：`.box` 框选 / `.under` 下划 / `.lead` 引线，三选一。两处批注等于没有重点。
- kicker（mono 顶标）+ `.rule` 短横线固定在 (88,112) 起，是全系列的页眉签名。

## 字体

- 中文：PingFang SC 600，当"剪字"用；不再加粗、不描边、不加阴影。
- 数字：Helvetica Neue 700，超大 editorial 数字，`letter-spacing:-.05em`。数字是这个风格里最强的视觉物，能用数字扛的帧不要用长句扛。
- mono：Menlo，只用于编号 / 路径 / 单位 / 段标识，`letter-spacing:.18em`。
- 三个 family 已在 collage.css 顶部用 `@font-face + src:local()` 声明（渲染器字体解析需要），别删。

## 截图锚点纪律

- 没拿到真实截图：`.shot` 内放 `<div class="bars">`（宽度不一的灰条 + `.dots` 网点）做抽象文档，可加一条深色 `.ph` 标注"截图锚点位 · xxx"。这是占位符美学，不是假界面——**不画按钮、不画输入框、不写假 UI 文字**。
- 拿到截图：`bars` 整块换成 `<img src="assets/shots/xxx.png" class="shot-img">`，批注、布局、动效都不动。
- 引用的规矩：不是原文就不要框选放大（框选=向观众担保这是真的）。

## 禁止清单

黑底霓虹、任何渐变、玻璃拟态、通用 icon（火箭 / 闪电 / 齿轮 / 灯泡 / 对勾堆）、粒子、3D、SaaS 圆角卡、纯 vector 扁平插画、emoji。这个风格的全部装饰预算都花在纸质感上，任何"数字产品感"的元素都会破功。
